# Mambo Box 규칙

- **간결한 종결 어미 사용**: 기술 문서 작성 시 서술형보다는 명사형/개조식 등 간결한 종결 어미 사용
- **구분선 금지**: 마크다운 구분선(`---`) 사용 금지
- **섹션 번호 금지**: 제목(헤더)에 번호(예: `1.`, `1)`) 사용 금지
- **목록 기호 통일**: 목록 불릿 기호는 `-` 사용 (`*` 사용 금지)
- **마침표 생략**: 개조식 목록 및 기술 문서 문장 끝의 마침표(`.`) 제거
- **참고자료 통합**: 별도의 '참고 자료' 섹션을 만들지 않고 각 관련 섹션 내에 링크 포함
