# 오픈소스로 구성하는 모션 영상 제작 도구 모음

클로드 모션은 팀 플랜 이상에서 지원. [공식 안내](https://support.claude.com/ko/articles/17454997-claude-motion-시작하기)

## 1. 소재 생성·준비

- [ComfyUI](https://github.com/Comfy-Org/ComfyUI) — AI 이미지·영상 소재 생성
- [rembg](https://github.com/danielgatis/rembg) — 이미지 배경 제거·투명 소재 제작

## 2. 음성·자막 준비

- [VoiceStudio](https://github.com/debpalash/voicestudio) — 음성 제작·CosyVoice 모델 지원
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) — 음성 인식·자막 시간 추출

## 3. 모션 제작·영상 조합

- [Three.js](https://github.com/mrdoob/three.js) — 3D 장면·제품 애니메이션 제작
- [HyperFrames](https://github.com/heygen-com/hyperframes) — HTML 기반 모션 영상 제작·렌더링
- [Remotion](https://github.com/remotion-dev/remotion) — React 기반 영상 제작·렌더링 (선택 옵션, 커스텀 라이선스)

## 4. 후처리·최종 출력

- [FFmpeg](https://ffmpeg.org/) — 영상 변환·압축·오디오 믹싱

## 전체 제작 흐름 자동화

- [OpenMontage](https://github.com/calesthio/OpenMontage) — AI 에이전트 기반 영상 기획·소재 생성·편집·출력 자동화
