## 취약점 스캐닝 도구

취약점 스캐닝(Vulnerability Scanning)은 시스템·서비스·소프트웨어 의존성을 자동 점검해 알려진 취약점과 보안 설정 오류를 탐지하는 과정. 탐지 결과를 바탕으로 수정 우선순위를 정하고, 필요 시 모의해킹으로 실제 악용 가능성을 검증.

- [OpenVAS Scanner](https://github.com/greenbone/openvas-scanner) — OS
- [OSV-Scanner](https://github.com/google/osv-scanner) — 프로젝트 저장소

## AI 모의해킹 도구

모의해킹(Penetration Testing, Pentesting)은 허가된 범위에서 실제 공격 기법으로 시스템의 취약점과 침해 가능성을 검증하는 보안 점검. 자동 스캐닝으로 찾은 취약점의 악용 가능성과 영향을 확인하고 개선 방안을 도출.

- [PentestGPT](https://github.com/GreyDGL/PentestGPT)
- [PentAGI](https://github.com/vxcontrol/pentagi)
