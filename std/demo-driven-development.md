# 데모 중심 개발 (Demo-Driven Development)

- [데모 중심 개발 - GeekNews](https://news.hada.io/topic?id=20749)

## Summary

SaaS 솔루션 제품에서 고객 확보를 위한 라이브 데모에 맞추어 기능 개발을 진행하는 방식.

## Issues

- **기능 플래그로 확장되는 설정 지옥**: 고객별 요구사항을 수용하기 위해 플래그가 난립하고, 데모 후 미도입 고객의 플래그가 방치됨.
- **완성된 제품이라는 착각**: 빠른 피드백 수렴 목적보다 보여주기식 개발이 되기 쉬우며, 사업팀의 기대치와 개발팀의 완성도 인식 간 괴리가 발생함.
